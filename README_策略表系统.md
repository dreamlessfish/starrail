# 基于策略表的购买自动化系统

## 系统概述

本系统采用**离线策略表（Excel Lookup）**的方式来决定购买行为，替代原有的基于图像识别的决策逻辑。

## 文件说明

1. **strategy_generator.py** - 策略表生成器
   - 生成包含所有可能手牌状态的Excel策略表
   - 输出文件：`H:\starrail\strategy_table.xlsx`

2. **main.py** - 基于策略表的主程序
   - 使用策略表进行离线决策
   - 保留图像识别和拖动逻辑用于执行操作

## 使用步骤

### 第一步：生成策略表

```bash
python strategy_generator.py
```

这将生成 `H:\starrail\strategy_table.xlsx` 文件，包含所有可能的手牌状态和对应的决策。

### 第二步：运行主程序

```bash
python main.py
```

程序启动后会要求你输入初始手牌状态（格式：1星数量,2星数量,3星数量）

例如：
- `0,0,0` - 空手牌
- `2,1,0` - 2个1星，1个2星
- `0,0,1` - 1个3星

## 合成规则

- **3个1星** → **1个2星 + 1个1星**（Buff：合成后保留1个1星）
- **3个2星** → **1个3星**

## 决策类型

策略表中的决策类型：

- **Buy** - 购买：合成后总占用≤3格，可以购买
- **Buy & Sell** - 购买并售卖：合成后出现了3星，购买后进入售卖流程
- **Refresh** - 刷新：合成后占用>3格（卡格子），不买，直接刷新
- **Sell** - 售卖：商店刷出0张，但手牌有3星，直接进入售卖流程

## 控制热键

- **F10** - 启动脚本
- **F11** - 暂停脚本
- **F12** - 退出程序

## 配置说明

在 `main.py` 的 `main()` 函数中可以配置：

- 策略表路径
- 目标卡牌图像列表（用于识别商店中的1星牌）
- 手牌售卖图像
- 商店区域、手牌区域、售卖位置
- 各种等待时间参数

## 依赖安装

确保安装以下Python包：

```bash
pip install pandas openpyxl pyautogui keyboard
```

## 注意事项

1. 首次使用前必须先运行 `strategy_generator.py` 生成策略表
2. 手牌状态总数不能超过3格
3. 程序会自动维护手牌状态，根据购买和售卖操作更新
4. 确保图像文件路径正确，用于识别商店中的卡牌
